# -AI-Powered-Digital-Twin-of-India-s-Climate
An AI-powered Digital Twin platform for India's climate that provides real-time weather monitoring, climate analytics, air quality monitoring, AI-based climate insights, and interactive visualization using national climate datasets.
## 📌 Project Overview

This project aims to create a dynamic digital twin of India's climate by integrating weather APIs, AI models, and interactive dashboards. It helps users monitor climate conditions, analyze environmental risks, and generate intelligent climate reports.

---

## ✨ Features

- 🌤 Live Weather Dashboard
- 🌡 Real-Time Temperature Monitoring
- 💧 Humidity Monitoring
- 🌬 Wind Speed Monitoring
- 🌫 Air Quality Index (AQI)
- 📅 5-Day Weather Forecast
- 🗺 Interactive India Map
- 🌍 Climate Intelligence Panel
- 🚨 Weather Alerts
- 📊 Climate Analytics Dashboard
- 🤖 AI Climate Insights
- ⚠ Climate Risk Assessment
- 🌪 Cyclone Tracker
- 🌦 Weather Radar
- 🔥 Live Heat Map
- 📈 Interactive Charts
- 📄 PDF Climate Report Download
